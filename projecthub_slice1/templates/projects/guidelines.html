Project guidelines

Academic workflow

  1. Propose a project title and problem statement.
  2. Secure supervisor acceptance and formal approval.
  3. Set milestones and keep meeting logs updated.
  4. Submit progress evidence before the defence stage.
  5. Archive the completed project for repository reuse and follow-on work.

Recommended milestones

  • Topic selection and problem framing
  • Literature review and project plan
  • Implementation and testing
  • Draft report and presentation preparation
  • Defence and final archival
